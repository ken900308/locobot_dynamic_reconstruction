# Legacy MASt3R-SLAM Files

這裡的內容不在目前 LoCoBot
`2_mast3r_slam.sh → launch_mast3r_visual_ros2_igbr.sh`
啟動鏈上，只供歷史追溯。

- `launchers/`：舊 v1、no-ROS 與 Unity launchers。
- `entrypoints/`：舊 ROS implementations 與 PLY publisher。
- `evaluation/`：dataset entrypoint、download/eval scripts、groundtruths
  與 evaluation-only configs。
- `backups/`：backup、original setup 與下載紀錄。
- `modules/tictoc.py`：active module graph 未使用的 GPU timing helper。
- `upstream_README.md`、`media/`：原始 upstream demo 文件與素材。

封存檔案的舊相對路徑可能失效，不保證可直接執行。
